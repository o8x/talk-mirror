# Talk-mirror 技能

Talk-mirror 是一个自包含的远程调试器：客户端通过 TCP/UDP 推送调试数据，平台负责
存储并通过 Web 界面展示。它同时暴露一个基于 HTTPS 的 REST API（默认端口 `443`）用于
查询，以及一个 HTTP 摄入端点用于写入日志消息。

## 前置条件

- **基础地址**：`https://<host>:443`（Talk-mirror 服务器地址）。
- **TLS**：服务器默认使用自签名证书，因此 `https_request` 工具必须允许不安全连接
  （`verify: false`）。
- **认证**：默认无需认证。

## 交互方式

用户在与「魔镜」对话。将其请求映射到下面某个模块，并使用 `https_request` 工具发起
对应的 HTTP 调用。

| 模块 | 用途 | 文件 |
|------|------|------|
| 查询 | 查看连接、会话、消息、统计、设置、接入示例代码 | `query/SKILL.zh-CN.md` |
| 日志写入 | 通过 HTTP 写入一条调试日志 | `logging/SKILL.zh-CN.md` |

请阅读对应模块文件以获取准确的端点、参数与示例。

## 提示词规则

- **查询** —— 提示词以「魔镜魔镜告诉我」开头，后接用户想了解的内容：

  > 魔镜魔镜告诉我，现在有哪些连接？
  > 魔镜魔镜告诉我，这个会话里最近有什么消息？

- **写入** —— 提示词以「魔镜魔镜，请记录」开头，后接日志内容：

  > 魔镜魔镜，请记录一条日志：支付成功，订单号 12345。

## 提示词规则生成

针对每个能力，按以下模板生成一条规则：

```
触发词 : <拟人化提示词>
意图   : <用户想要什么>
动作   : <HTTP 方法> <路径> [?查询参数]
请求体 : <请求体，如有>
回复   : <如何总结响应>
```

每个模块都按此模板列出各能力对应的具体触发词与规则。
