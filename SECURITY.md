# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report vulnerabilities privately by emailing the maintainers. We aim to
acknowledge reports within 48 hours and provide a fix or mitigation as soon as
possible.

## Supported versions

Security fixes are applied to the latest release. Older releases are not
supported.

| Version | Supported          |
|---------|--------------------|
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting

Please include:

- The affected version
- A description of the vulnerability
- Steps to reproduce (if possible)
- Any suggested fix
